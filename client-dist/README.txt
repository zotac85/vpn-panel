Скрипт: /root/create-client.sh
Дата:   создан 16.10.2026


───────────────────────────────────────────────────────────
НАЗНАЧЕНИЕ
───────────────────────────────────────────────────────────

Автоматически собирает персональный архив для нового клиента:

  • Копирует шаблон из /root/client-pack
  • Вставляет токен клиента в 03_ТОКЕН.txt
  • Добавляет имя клиента и дату выдачи
  • Упаковывает в ZIP в /root/clients/


───────────────────────────────────────────────────────────
ИСПОЛЬЗОВАНИЕ
───────────────────────────────────────────────────────────

Команда:

  /root/create-client.sh <имя_клиента> <токен>

Пример:

  /root/create-client.sh ivan github_pat_11ABC123...


───────────────────────────────────────────────────────────
ЧТО ПРОИСХОДИТ
───────────────────────────────────────────────────────────

1. Создаётся папка /root/clients/client-ivan/
2. Туда копируются 4 файла из шаблона
3. В 03_ТОКЕН.txt вставляется токен клиента
4. В 00_ПРОЧТИ_МЕНЯ.txt добавляется имя и дата выдачи
5. Всё пакуется в /root/clients/client-ivan.zip


───────────────────────────────────────────────────────────
ПОСЛЕ СОЗДАНИЯ
───────────────────────────────────────────────────────────

1. Скачать архив: /root/clients/client-ivan.zip
2. Отправить клиенту (Telegram, email, ссылка)
3. Записать в реестр (см. ниже)


───────────────────────────────────────────────────────────
СОЗДАНИЕ ТОКЕНА ДЛЯ КЛИЕНТА
───────────────────────────────────────────────────────────

1. Открой: https://github.com/settings/tokens?type=beta
2. Generate new token
3. Заполни:
     Token name: client-ivan-2026-10
     Expiration: 90 дней
     Repository access: Only select repositories → vpn-panel
     Permissions:
       Contents: Read-only
       Metadata: Read-only
4. Скопируй токен
5. Запусти скрипт с этим токеном


───────────────────────────────────────────────────────────
РЕЕСТР ТОКЕНОВ
───────────────────────────────────────────────────────────

ВЕДИ СПИСОК выданных токенов! Без него не поймёшь что отзывать.

Формат:

  Клиент      Токен                      Дата         Истекает    Статус
  ivan        github_pat_11ABC...        2026-10-16   2027-01-14  активен
  petr        github_pat_11XYZ...        2026-10-20   2027-01-18  активен


───────────────────────────────────────────────────────────
ОТЗЫВ ТОКЕНА КЛИЕНТА
───────────────────────────────────────────────────────────

Если клиент ушёл или токен утёк:

1. Открой: https://github.com/settings/tokens?type=beta
2. Найди токен по имени (client-ivan-2026-10)
3. Нажми Delete / Revoke
4. Токен сразу перестаёт работать


───────────────────────────────────────────────────────────
ОБНОВЛЕНИЕ ШАБЛОНА
───────────────────────────────────────────────────────────

Если нужно изменить текст инструкции для будущих клиентов:

1. Измени файлы в /root/client-pack/
2. Следующие клиенты получат обновлённую версию
3. Старые клиенты — нет (у них уже архив готов)


───────────────────────────────────────────────────────────
СТРУКТУРА ШАБЛОНА
───────────────────────────────────────────────────────────

  /root/client-pack/
    00_ПРОЧТИ_МЕНЯ.txt          — общая информация
    01_ИНСТРУКЦИЯ.txt           — полная инструкция (419 строк)
    02_ПРОЧТИ_МЕНЯ_ПЕРВЫМ.txt   — что делать в первую очередь
    03_ТОКЕН.txt                — токен (заменяется на токен клиента)


───────────────────────────────────────────────────────────
ПОЛЕЗНО ЗНАТЬ
───────────────────────────────────────────────────────────

• Много клиентов — запускай скрипт по одному для каждого
• Тестовый запуск:
    /root/create-client.sh test github_pat_11XXX...
  создаст client-test.zip
• Удалить архив:  rm /root/clients/client-ivan.zip
• Очистить все:   rm -rf /root/clients/client-*.zip

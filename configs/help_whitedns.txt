💎 <b>Шаг 2. Как купить WhiteDNS</b>

1. Открой бота → «👤 Личный кабинет»
2. Нажми кнопку <b>💎 WhiteDns</b>
3. Пополни баланс (если нужно):
   • Через Stars, USDT или крипту
   • Минимум 1 USDT
4. Выбери тариф и оплати с баланса
5. После оплаты откроется доступ к настройке

━━━━━━━━━━━━━━━━━━━━
🎛 <b>Шаг 3. Как выбрать настройки</b>

Открой «💎 WhiteDns» в кабинете и пройди 3 шага:

<b>1️⃣ ВЫБЕРИ СЕРВЕР</b>
   🇩🇪 Германия — стабильный, для Европы
   🇫🇮 Финляндия — быстрый, для СНГ
   🇸🇪 Швеция — резервный

<b>2️⃣ ВЫБЕРИ ПРОФИЛЬ</b>
   📱 <b>3G</b>   — мобильная сеть
   📶 <b>WiFi</b>  — домашний Wi-Fi
   🖥 <b>ADSL</b>  — проводной интернет

   💡 Если не уверен — выбери <b>WiFi</b>.

<b>3️⃣ ПОДТВЕРДИ</b>
   Проверь выбор → «✅ ДА, ВСЁ ВЕРНО»

Бот пришлёт <b>3 файла</b>:
   📄 <code>connection.txt</code> — сервер
   📄 <code>settings.txt</code>   — настройки
   📄 <code>resolvers.txt</code>  — список DNS

━━━━━━━━━━━━━━━━━━━━
📥 <b>Шаг 4. Импорт в WhiteDNS</b>

⚠️ <b>Импортируй ИМЕННО в эти разделы:</b>

🔗 <code>connection.txt</code> → <b>Connection</b>
   → IMPORT → вставь текст
   → <b>напиши имя</b> (например «VPN»)
   → сохрани

⚙️ <code>settings.txt</code> → <b>Setting</b>
   → IMPORT → вставь текст
   → <b>напиши имя</b> (например «WiFi»)
   → сохрани

📡 <code>resolvers.txt</code> → <b>Resolver</b>
   → CREATE → вставь список
   → <b>напиши имя</b> (например «DNS»)
   → SAVE

⚠️ <b>ВАЖНО:</b> без имени профиля выдаст ошибку
<i>«Enter a profile name to save»</i> —
придумай любое, главное чтобы поле не было пустым.

❌ <b>Перепутаешь разделы — не заработает!</b>

━━━━━━━━━━━━━━━━━━━━
🚀 <b>Шаг 5. Подключение</b>

Вкладка <b>Connect</b> →
выбери свои профили →
нажми <b>CONNECT</b> 🔌

Появится <b>STOP</b> — значит подключено ✅

━━━━━━━━━━━━━━━━━━━━
⚠️ <b>Если не подключается:</b>

❌ <b>«No connection»</b>
→ Проверь что во вкладках Connection,
   Resolver и Setting выбраны твои профили.

❌ <b>Не работает интернет</b>
→ Отключи основной VPN.
→ Попробуй другой Resolver (смени сервер).

❌ <b>Медленно / отваливается</b>
→ В Resolver запусти «Background scan».
→ Попробуй другой сервер.

❌ <b>Файлы не открываются</b>
→ Используй X-plore для .txt из Telegram.

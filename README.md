# ⚡ Ultimate VPN Control Panel

Удобная интерактивная консольная панель для администрирования Linux VPN-серверов.

Запуск панели в любое время: vpn

​💎 Основные функции :

​Управление пользователями: создание аккаунтов, установка сроков действия, настройка лимитов устройств и мониторинг реального онлайна.

​MasterDnsVPN: установка, обновление, перезапуск службы и редактирование конфига.

​UDP Custom: развертывание туннелей и управление сетевыми портами.

​WebSocket Proxy: обход DPI блокировок и динамическая смена портов.

​Безопасность и оптимизация: настройка UFW, Fail2ban, включение TCP BBR и тюнинг сетевых буферов ядра.

⚙️ <b>НАСТРОЙКА HTTP CUSTOM</b>
━━━━━━━━━━━━━━━━━━━━

📲 <b>Шаг 1. Скачай приложение</b>

Установи <b>HTTP Custom</b> из Google Play:

<a href="https://play.google.com/store/apps/details?id=xyz.easypro.httpcustom">📥 Скачать HTTP Custom</a>

━━━━━━━━━━━━━━━━━━━━
🔗 <b>Шаг 2. Получи файл конфига</b>

Зайди в ЛК → «🔑 Мои ключи» → свой ключ →
нажми «📲 Получить конфиг».

Бот пришлёт файл с расширением <code>.hc</code>

━━━━━━━━━━━━━━━━━━━━
📋 <b>Шаг 3. Скачай файл</b>

Тапни на файл в сообщении бота →
<b>Скачать</b> → сохранится в <code>Download</code>.

━━━━━━━━━━━━━━━━━━━━
📥 <b>Шаг 4. Открой конфиг в приложении</b>

Открой HTTP Custom →
нажми на иконку <b>📄 Open Config</b>
(справа снизу).

Через файловый менеджер найди скачанный
<code>.hc</code> файл → выбери его.

Конфиг <b>автоматически</b> подтянется
во все поля ✨

━━━━━━━━━━━━━━━━━━━━
🚀 <b>Шаг 5. Подключение</b>

Нажми <b>CONNECT</b> 🔌

Через 3-5 секунд увидишь в логе
<b>HTTP/1.1 200 OK</b> и <b>101 Switching Protocols</b> —
значит подключено ✅

━━━━━━━━━━━━━━━━━━━━
💡 <b>Как сохранить свой конфиг</b>

Чтобы не открывать файл каждый раз:

• <b>Save Config</b> — сохранить в приложении
• <b>Cloud Config</b> — сохранить в облако

После этого конфиг появится в главном
меню и его можно подключать одним тапом.

━━━━━━━━━━━━━━━━━━━━
⚠️ <b>Если не подключается:</b>

❌ <b>«cannot connect to the host»</b>
→ Проверь интернет.
→ Переоткрой конфиг (Open Config заново).
→ Проверь что файл <code>.hc</code> не повреждён.

❌ <b>«Illegal packet size»</b>
→ Проблема с полезной нагрузкой (payload).
→ Переимпортируй файл от бота.

❌ <b>Файл не открывается</b>
→ Убедись что установлен файловый менеджер
   (X-plore, Files и т.п.).

❌ <b>Не находит файл в Open Config</b>
→ Проверь папку <code>Download</code>
   в файловом менеджере.

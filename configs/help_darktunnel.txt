📲 <b>Шаг 1. Скачай приложение</b>

📱 <b>Для Android:</b>
Установи DarkTunnel из Google Play.

💻 <b>Для ПК (Windows / macOS):</b>
Скачай наше приложение ArsenVPN:
https://github.com/zotac85/ArsenVpn

━━━━━━━━━━━━━━━━━━━━
🔗 <b>Шаг 2. Получи конфиг</b>

Зайди в личный кабинет бота →
«🔑 Мои ключи» → выбери свой ключ →
нажми «📲 Получить конфиг».

Бот пришлёт длинную ссылку,
начинающуюся с darktunnel://

━━━━━━━━━━━━━━━━━━━━
📋 <b>Шаг 3. Скопируй ссылку</b>

Тапни на ссылку в сообщении бота —
она скопируется в буфер обмена.

━━━━━━━━━━━━━━━━━━━━
📥 <b>Шаг 4. Импорт в DarkTunnel</b>

Открой DarkTunnel →
нажми ⋮ (три точки справа сверху)
   ↓
Import
   ↓
Clipboard

Конфиг появится в списке ✨

━━━━━━━━━━━━━━━━━━━━
🚀 <b>Шаг 5. Подключение</b>

Выбери свой конфиг →
нажми CONNECT 🔌

Через 3-5 секунд появится Connected ✅

━━━━━━━━━━━━━━━━━━━━
⚠️ <b>ВАЖНО — HWID-привязка</b>

Конфиг привязан к одному устройству
по HWID. Работать будет только на нём 🔒

📱 Сменил телефон?
Переустановил приложение?
Ошибка «config upgrade required»?

→ Зайди в ЛК → выбери ключ → нажми
   кнопку 🔄 → введи HWID нового
   устройства → получи свежий конфиг
   и импортируй его заново.

━━━━━━━━━━━━━━━━━━━━
🛠 <b>Если не подключается:</b>

❌ «Config upgrade required»
→ Неверный HWID. Обнови конфиг (см. выше).

❌ «Config locked to specific device»
→ Конфиг от другого устройства. Обнови.

❌ «Unexpected EOF»
→ Ссылка обрезана при копировании.
   Скопируй ещё раз целиком.

❌ «Connecting to server error»
→ Прокси недоступен. Попробуй позже
   или обнови конфиг (кнопка 🔄).

❌ Просто не коннектит
→ Проверь интернет / VPN выключен?

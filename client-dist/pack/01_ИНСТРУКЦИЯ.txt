───────────────────────────────────────────────────────────────
ШАГ 1. ЧТО НУЖНО ДЛЯ СТАРТА
───────────────────────────────────────────────────────────────

Перед началом убедись что у тебя есть:

✅ VPS (виртуальный сервер) с Ubuntu 22.04 / 24.04 / 26.04
   • Минимум:  1 CPU, 1 GB RAM, 10 GB SSD
   • Рекомендую: 2 CPU, 2 GB RAM, 20 GB SSD
   • Хостинги: Play2Go, NodeHost, DataPisa, Aeza, VDSina

✅ Root-доступ к серверу (IP + пароль или SSH-ключ)

✅ Токен доступа VPN Panel (выдаёт @ArsenGuro лично)

✅ Аккаунт в Telegram

✅ Терминал (SSH-клиент):
   • На телефоне: Termux (Android) или Termius (iOS)
   • На ПК: PuTTY / Windows Terminal / iTerm (Mac)
   • Или веб-консоль хостинга (панель VPS)


───────────────────────────────────────────────────────────────
ШАГ 2. ПОДКЛЮЧЕНИЕ К СЕРВЕРУ
───────────────────────────────────────────────────────────────

Открой терминал и подключись:

   ssh root@IP_АДРЕС_СЕРВЕРА

Например:

   ssh root@144.31.28.219

Введи пароль (тот, что выдал хостинг).

При первом подключении спросит:
   "Are you sure you want to continue connecting? (yes/no)"
Отвечай: yes

Если ты на телефоне через Termux — сначала:
   pkg install openssh
   ssh root@IP_АДРЕС_СЕРВЕРА


───────────────────────────────────────────────────────────────
ШАГ 3. ОБНОВЛЕНИЕ СИСТЕМЫ (рекомендуется)
───────────────────────────────────────────────────────────────

Один раз, перед установкой:

   apt update && apt upgrade -y

Займёт 1-3 минуты. Если спросит что-то — жми Enter.


───────────────────────────────────────────────────────────────
ШАГ 4. УСТАНОВКА VPN PANEL
───────────────────────────────────────────────────────────────

Выполни одну команду:

   bash <(curl -Ls https://raw.githubusercontent.com/zotac85/vpn-install_1.0/main/install.sh)

Что произойдёт:

1. Скрипт попросит ТОКЕН ДОСТУПА
   • Вставь токен из файла 03_ТОКЕН.txt
   • Токен сохранится на сервере (потом не придётся вводить)

2. Скрипт начнёт загрузку и установку
   • Установит git, python3, зависимости
   • Развернёт панель управления
   • Настроит автозапуск

3. Скрипт спросит "Тип установки":
   • Выбери "1" — Мастер (полная установка)

4. Установка завершится сообщением:
   "🟢 Операция успешно завершена, Хозяин!"

Если что-то пошло не так — скопируй ошибку и напиши @ArsenGuro.


───────────────────────────────────────────────────────────────
ШАГ 5. СОЗДАНИЕ БОТОВ В TELEGRAM
───────────────────────────────────────────────────────────────

Тебе нужно 2 бота:
   БОТ №1 — Основной (для выдачи ключей)
   БОТ №2 — Поддержки (для тикетов)

─────────────────────────────────────
5.1. Создание основного бота
─────────────────────────────────────

1. Открой Telegram → найди @BotFather
2. Отправь команду: /newbot
3. BotFather спросит имя бота (видимое):
   • Введи: "Мой VPN" (или любое)
4. BotFather спросит username (уникальный, заканчивается на "bot"):
   • Введи: "MyVpnBot" (если занято — попробуй другое)
5. BotFather пришлёт ТОКЕН вида:
   1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   • СОХРАНИ ЕГО! Он нужен для настройки.

─────────────────────────────────────
5.2. Создание бота поддержки
─────────────────────────────────────

1. Снова /newbot в @BotFather
2. Имя: "Мой VPN Support"
3. Username: "MyVpnSupportBot" (любое другое)
4. Сохрани второй ТОКЕН.

─────────────────────────────────────
5.3. Узнать свой Telegram ID
─────────────────────────────────────

1. Открой @userinfobot
2. Отправь /start
3. Он пришлёт твой ID (например: 1738878748)
   • СОХРАНИ ID! Он нужен для настройки.


───────────────────────────────────────────────────────────────
ШАГ 6. НАСТРОЙКА ПАНЕЛИ
───────────────────────────────────────────────────────────────

Запусти панель:

   vpn

Ты увидишь меню:

   ⚡ ULTIMATE VPN CONTROL PANEL ⚡

   1) 👥 Управление пользователями
   2) 🕸️ WebSocket Proxy (Кастомный)
   3) ⚡ UDP Custom (Управление)
   4) 🌐 MasterDnsVPN
   5) 🛡️ Безопасность и Оптимизация
   6) 🚫 Блокировка торрентов
   7) 💎 Telegram-бот
   8) 🔄 Обновить скрипт ВПН
   9) 📡 Управление нодами
   0) 🚪 Выход

─────────────────────────────────────
6.1. Настройка основного бота
─────────────────────────────────────

Шаги в панели:
   7 → 6) 🤖 Основной бот → 1) 🔑 Изменить BOT_TOKEN
   • Вставь ТОКЕН от основного бота (из шага 5.1)

   0 (назад) → 7 → 6) Основной бот → 2) 👤 Изменить ADMIN_ID
   • Вставь свой Telegram ID (из шага 5.3)

   0 → 7 → 6) Основной бот → 3) 🚀 Полная установка / настройка
   • Скрипт всё настроит и запустит

─────────────────────────────────────
6.2. Настройка бота поддержки
─────────────────────────────────────

Шаги в панели:
   7 → 7) 💬 Бот поддержки → 1) 🔑 Изменить BOT_TOKEN
   • Вставь ТОКЕН от бота поддержки (из шага 5.2)

   0 → 7 → 7) Бот поддержки → 3) 🚀 Установка / переустановка
   • Скрипт настроит сервис

─────────────────────────────────────
6.3. Локация и тарифы
─────────────────────────────────────

Локация сервера (то что видят клиенты):

   7 → 6) Основной бот → 4) 📝 Изменить SERVER_LOCATION
   • Пример: "Германия 🇩🇪"
   • Или:    "Финляндия 🇫🇮"

Тарифы VIP:

   7 → 11) 💎 Тарифы VIP → 1) ✏️ Изменить тарифы

   Формат: дни|цена|ГБ|устройства,дни|цена|ГБ|устройства,...

   Пример:  15|3|100|1,30|5|300|2,90|14|900|3

   Читается так:
      15 дней — 3 USDT — 100 ГБ — 1 устройство
      30 дней — 5 USDT — 300 ГБ — 2 устройства
      90 дней — 14 USDT — 900 ГБ — 3 устройства

Тестовые параметры:

   7 → 9) ⏰ Кулдаун / срок / лимиты
   • TEST_HOURS — сколько часов длится тест (например 2)
   • TEST_DEVICES — сколько устройств (например 1)
   • TEST_TRAFFIC_GB — сколько ГБ (например 30)
   • COOLDOWN_HOURS — кулдаун между тестами (например 8)


───────────────────────────────────────────────────────────────
ШАГ 7. ПЕРВЫЙ ЗАПУСК И ПРОВЕРКА
───────────────────────────────────────────────────────────────

1. Открой своего основного бота в Telegram
   • Например: @MyVpnBot (тот username что ты создал)

2. Отправь /start

3. Должно прийти приветствие с кнопкой "Получить тест"

4. Нажми кнопку → отправь свой HWID → получи тестовый ключ

   HWID — ID устройства из DarkTunnel:
   DarkTunnel → ⚙️ Settings → внизу Hardware ID → скопируй

Если всё работает — панель готова! 🎉


───────────────────────────────────────────────────────────────
ШАГ 8. НАСТРОЙКА SSH-БАННЕРА
───────────────────────────────────────────────────────────────

Когда клиент подключается к серверу — он видит баннер.

Настройка через панель:
   4) 🌐 MasterDnsVPN → найти пункт "Установка баннера"
   ИЛИ
   5) 🛡️ Безопасность → найти пункт "SSH-баннер"

Баннер автоматически подтянется из репозитория и подставит:
   • Название канала
   • Локацию сервера
   • Лимит устройств
   • Ссылки на поддержку и бота

Что появится в баннере (пример):

   📢 Канал: @YourChannel
   📍 Локация: Германия 🇩🇪

   ❌ DDOS · Взлом · Торренты · Спам
   📱 2 устр. · 🚫 Нарушение = бан

   💬 Поддержка: @YourSupportBot
   🤖 Бот: @YourVpnBot


───────────────────────────────────────────────────────────────
ШАГ 9. ДОБАВЛЕНИЕ ВТОРОГО СЕРВЕРА (НОДЫ)
───────────────────────────────────────────────────────────────

Если хочешь чтобы клиенты могли подключаться к нескольким
локациям — устанавливаешь ноды.

НОДА — сервер БЕЗ панели и ботов, только SSH + WS.
Нужна чтобы:
   • Клиенты сами выбирали локацию
   • Нагрузка распределялась
   • Был резервный сервер

─────────────────────────────────────
9.1. Установка ноды на новом сервере
─────────────────────────────────────

На НОВОМ сервере (чистый Ubuntu) выполни:

   1) Создай файл токена:
      echo "ТВОЙ_ТОКЕН" > /root/.vpn-panel.token
      chmod 600 /root/.vpn-panel.token

   2) Скачай и запусти install-node.sh:
      git clone --depth 1 "https://$(cat /root/.vpn-panel.token)@github.com/zotac85/vpn-panel.git" /tmp/vpn-src
      bash /tmp/vpn-src/install-node.sh

   Скрипт спросит:
      • WS-порт   (Enter = 2052)
      • SSH-порт  (Enter = 22)

─────────────────────────────────────
9.2. Подключение ноды к мастеру
─────────────────────────────────────

На МАСТЕРЕ (где панель):

   vpn → 9) 📡 Управление нодами
   → 1) Добавить ноду
   → Введи название, IP, порт

Затем в том же меню:
   → 4) Закинуть SSH-ключ на ноду
   → 2) Проверить все ноды

Готово! Юзеры автоматически создаются на всех нодах,
клиенты получают .dark файлы со всех локаций.

ШАГ 10. ЧАСТЫЕ ПРОБЛЕМЫ
───────────────────────────────────────────────────────────────

❓ "Не удалось загрузить репозиторий"
   → Токен неверный или истёк
   → Проверь: cat /root/.vpn-panel.token
   → Напиши @ArsenGuro для замены токена

❓ "BOT_TOKEN не задан"
   → Не заполнен bot.conf
   → vpn → 7 → 6) Основной бот → 1) Изменить BOT_TOKEN

❓ Бот не отвечает на команды
   → systemctl is-active vpn-tg-bot
   → Если inactive:
     systemctl status vpn-tg-bot --no-pager -l
   → Логи: tail -50 /var/log/vpn-tg-bot.log

❓ Ключ генерируется, но клиент не подключается
   → Проверь WS-порт:
     awk -F'=' '/listen_port/ {print $2}' /usr/local/bin/ws-proxy.py
   → Проверь UFW: ufw status
   → Порт WS должен быть открыт

❓ "config upgrade required" в DarkTunnel
   → HWID не совпадает с конфигом
   → Клиент должен отправить свой HWID в бот заново
   → В админке можно пересоздать конфиг: /admin → VIP → ключ → 🔄

❓ Панель не открывается (команда vpn не найдена)
   → Установка не завершилась успешно
   → Переустанови: bash <(curl -Ls ...install.sh)

   vpn → 5) Безопасность → 18) 💾 Создать бэкап сейчас

Список бэкапов:
   vpn → 5) → 19) 📂 Список бэкапов

Восстановление из бэкапа:
   vpn → 5) → 20) 📥 Восстановить из файла

ШАГ 12. БЕЗОПАСНОСТЬ
